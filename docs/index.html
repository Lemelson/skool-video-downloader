Skool Video Downloader & Course Archiver

A free, open-source command-line toolkit to download and back up your own Skool videos, lessons, PDFs and community posts for offline access.

View on GitHub Read the docs

What it does

Skool Video Downloader drives a real, logged-in Chrome session over the Chrome DevTools Protocol, so it reuses your own authenticated session and never asks for your password. Point it at content you already have access to and keep a clean, personal offline backup.

🎥 Download videos

Capture the media URLs behind lessons you can access and save the videos locally.

📄 Save resources

Download attached PDF resources and lesson details in one pass.

💬 Archive posts

Turn community feed posts you can see into clean offline HTML, Markdown and JSON.

🗜️ Optimize storage

Re-encode oversized videos down to efficient 1080p to reclaim disk space.

⚖️ Responsible use

This project ships only the tooling — no course content. Use it only to archive material you have lawful, authorized access to (such as a course you purchased or a community you belong to), and only for your own personal, offline use.

Do not redistribute, re-upload, resell or publicly share downloaded material. You are responsible for complying with Skool's Terms of Service, the rights of content creators, and the laws of your jurisdiction. A downloader is a neutral tool, like yt-dlp or a browser's "Save As".

Quick start

1. Install the toolchain

npm install
python3 -m pip install -U yt-dlp
brew install ffmpeg   # or: sudo apt-get install ffmpeg

2. Launch Chrome with remote debugging and log in to Skool

/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 --user-data-dir="$HOME/.skool-archive-chrome"

3. Run a script

export SKOOL_ARCHIVE_ROOT="$HOME/Skool-Backup"

# List the course structure of a classroom you can access
node scripts/cdp_course_state.js "https://www.skool.com/<community>/classroom/<id>"
